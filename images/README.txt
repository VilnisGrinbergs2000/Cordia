CORDIA artwork

Legacy: the geometric symbol and the dark rounded-square icons below are no
longer used anywhere. Codi is the logo and the app icon now; the shipped icon
set is generated from client/public/codi.png by client/scripts/gen-icons.mjs
(npm run icons).

- cordia-symbol.svg: standalone symbol with transparent background (legacy).
- cordia-app-icon-dark.svg: dark rounded-square app icon (legacy).
- cordia-app-icon-light.svg: light rounded-square app icon (legacy).
- PNG files are raster exports at 1024, 512, and 256 pixels when included.

SVG files are scalable vector artwork and contain no sheet labels or mockup text.
Colors: charcoal #0F1117, lavender #A78BFA, mint #6EE7B7, light #F5F4FF.
